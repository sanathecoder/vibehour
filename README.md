# VibeHour - Luxury Watch E-Commerce Platform

VibeHour is a premium, fully responsive e-commerce web application designed for luxury watch enthusiasts, featuring interactive UI, smooth animations, and robust backend management.

## 🎥 Project Demo

## ✨ Key Features
*   **Premium Aesthetic:** Elegant design with Framer Motion animations for a high-end feel.
*   **Full-Stack Power:** Built with the MERN stack (MongoDB, Express, React, Node.js).
*   **Role-Based Access:** Dedicated Admin dashboard for managing products and tracking orders.
*   **Smooth UX:** Persistent cart management and seamless user authentication.

## 🛠 Tech Stack
*   **Frontend:** React.js, Tailwind CSS, Framer Motion
*   **Backend:** Node.js, Express.js
*   **Database:** MongoDB
*   **Media Storage:** ImageKit
